# FrameworkType

#### 函数功能

设置原始模型的框架类型。  

#### 函数原型

```
OpRegistrationData &FrameworkType(const domi::FrameworkType &fmk_type)
```

#### 参数说明

|参数|输入/输出|说明|
|:-------|:----|:------------------------------------------------------------------------------------------------------------------|
|fmk_type|输入|框架类型。 - CAFFE - TENSORFLOW - ONNX FrameworkType枚举值如下：CAFFE、MINDSPORE、TENSORFLOW、ANDROID_NN、ONNX、FRAMEWORK_RESERVED。|
